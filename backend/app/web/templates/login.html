This dashboard reads the session cookie the API sets.

There is no sign-in form here, and that is deliberate: a form on this page would be a second credential path to maintain and a second place to get wrong. Authenticate against the API, which sets the session cookie this page reads:

curl -c cookies.txt -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.test","password":"..."}'

Or use aegis-ai login. Then reload this page.
